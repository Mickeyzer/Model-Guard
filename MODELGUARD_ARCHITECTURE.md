## 1. What ModelGuard Does

ModelGuard is a middleware proxy that sits in front of any deployed ML model API and detects **model stealing attacks** in real time.

A model stealing attack is when an adversary sends many crafted queries to a model API to reconstruct the model's decision boundaries without access to the training data or weights. ModelGuard fingerprints the *behavioral pattern* of queries (not their content) using an XGBoost classifier, assigns a threat score, and applies a tiered defense response.

```
[Client / Adversary]
        │
        ▼  POST /predict
[ModelGuard Middleware :8000]  ←── fingerprints queries, applies defense
        │
        ▼  (only if tier 0 or 1)
[Protected ML Model :8001]
        │
        ▼
   Response returned (possibly modified)

[Streamlit Dashboard :8501]  ←── reads SQLite, shows live stats
```

## 6. Feature Extractor (`middleware/feature_extractor.py`)

Input: a list of `QueryLog` ORM objects (the recent query window for one IP).
Output: a dict of exactly 7 float features.

```python
def extract_behavioral_features(recent_queries: list[QueryLog]) -> dict:
    """
    Computes 7 behavioral features from a sliding window of queries.
    Returns a dict with exactly these keys (all floats):
    
    1. query_count_1min (float)
       Simply len(recent_queries) cast to float.

    2. mean_inter_query_time_ms (float)
       Mean of all inter_query_time_ms values in recent_queries.
       If only one query, return 0.0.

    3. feature_space_entropy (float)
       For each of the 4 feature dimensions, bin the values into 10 equal-width bins
       over range [0, 10]. Compute Shannon entropy of the bin counts.
       Return the mean entropy across all 4 dimensions.
       Formula: H = -sum(p * log2(p+1e-9) for p in bin_probabilities)

    4. prediction_entropy (float)
       Take all raw_prediction values (use returned_prediction if raw_prediction is None).
       Compute Shannon entropy of the 3-class distribution.
       e.g. if all predictions are class 0: entropy = 0.0 (no diversity = suspicious uniform sweep)
       If equally distributed: entropy = log2(3) ≈ 1.585

    5. boundary_proximity_score (float)
       For each query, take max(returned_probabilities).
       boundary_proximity_score = fraction of queries where max_prob < 0.70.
       High score means attacker is probing near decision boundaries.

    6. input_variance (float)
       For each of the 4 feature columns, compute variance across all queries.
       Return the mean of the 4 variances.
       High variance = sweeping input space (attack). Low variance = normal user.

    7. repetition_ratio (float)
       For each query i, check if any previous query j (j < i) has
       L2_distance(features_i, features_j) < 0.1.
       repetition_ratio = count of repeated queries / total queries.
       Return 0.0 if fewer than 2 queries.
    
    If recent_queries is empty, return all zeros.
    If recent_queries has < 3 entries, compute what you can and return 0.0 for features
    that require more data (e.g. repetition_ratio).
    """
```

## 7. Fingerprint Engine (`middleware/fingerprint_engine.py`)

```python
# Module-level: load XGBoost model once at import time
# MODEL_PATH = os.getenv("FINGERPRINT_MODEL_PATH", "data/fingerprint_model.pkl")
# _model = joblib.load(MODEL_PATH)  — wrapped in try/except, log warning if not found

FEATURE_ORDER = [
    "query_count_1min",
    "mean_inter_query_time_ms",
    "feature_space_entropy",
    "prediction_entropy",
    "boundary_proximity_score",
    "input_variance",
    "repetition_ratio",
]
# Features must always be passed to the model in this exact order as a numpy array.

def classify_query(recent_queries: list[QueryLog]) -> dict:
    """
    1. Call feature_extractor.extract_behavioral_features(recent_queries)
    2. Build numpy array in FEATURE_ORDER
    3. Call _model.predict_proba(features_array)[0][1] → threat_score (float 0–1)
    4. Return:
       {
         "threat_score": float,
         "features_used": dict,   # the 7 features, for logging/debug
         "model_loaded": bool     # False if model file was missing at startup
       }
    If model not loaded, return {"threat_score": 0.0, "features_used": {}, "model_loaded": False}
    """
```

## 8. Training Data Generation (`data/generate_training_data.py`)

Generates `data/training_data.csv` with columns:
`query_count_1min, mean_inter_query_time_ms, feature_space_entropy, prediction_entropy, boundary_proximity_score, input_variance, repetition_ratio, label`

label = 0 (normal) or 1 (attack)

**Normal sessions (500 sessions):**
```
queries_per_session: randint(5, 25)
inter_query_time_ms: uniform(2000, 30000)  # 2–30 seconds
features: sampled from N(μ, σ) where μ=[5.8, 3.0, 3.7, 1.2], σ=[0.8, 0.4, 1.7, 0.7]
  (roughly Iris dataset distribution)
predictions: dominated by one class with occasional switches
→ Expected output: low entropy, low boundary_proximity, low variance, low repetition
```

**Attack sessions — Naive (167 sessions):**
```
queries_per_session: randint(40, 80)
inter_query_time_ms: uniform(100, 500)  # very fast
features: uniform grid sweep, each feature in linspace(0, 8, 20)
predictions: spread across all 3 classes (full space coverage)
→ Expected output: high entropy, high variance, low boundary_proximity, low repetition_ratio
```

**Attack sessions — Adaptive/Boundary (167 sessions):**
```
queries_per_session: randint(20, 50)
inter_query_time_ms: uniform(200, 1000)
features: start from random point, perturb by small delta each step
  such that returned max_probability is between 0.45 and 0.65
predictions: mixed (near boundary)
→ Expected output: high boundary_proximity_score, moderate entropy, low variance
```

**Attack sessions — Knockoff/High Volume (166 sessions):**
```
queries_per_session: randint(60, 120)
inter_query_time_ms: uniform(50, 300)  # fastest
features: uniform(0, 8) random for each feature each query
predictions: spread across classes
→ Expected output: highest query_count_1min, lowest inter_query_time, high entropy
```

For each session, compute all 7 features using the same formulas as `feature_extractor.py`.
Write one row per session to CSV.
Print class distribution and basic stats before saving.

## 10. Defense Module (`middleware/defense.py`)

### Rate Limiter (in-memory)

```python
# Use collections.defaultdict(deque) to store timestamps per IP
# _rate_limit_store: dict[str, deque[datetime]] = defaultdict(deque)

def is_rate_limited(client_ip: str) -> bool:
    """
    Remove timestamps older than RATE_LIMIT_WINDOW_SECONDS from deque.
    If len(deque) >= RATE_LIMIT_MAX_REQUESTS: return True (rate limited).
    Else: append current timestamp, return False.
    """
```

### Tier Assignment

```python
def get_tier(threat_score: float) -> int:
    """
    threat_score < THREAT_TIER1_THRESHOLD  → 0
    threat_score < THREAT_TIER2_THRESHOLD  → 1
    threat_score < THREAT_TIER3_THRESHOLD  → 2
    threat_score < THREAT_TIER4_THRESHOLD  → 3
    else                                    → 4
    All thresholds read from environment variables.
    """
```

### Response Modifiers

```python
def perturb_probabilities(probabilities: list[float], sigma: float) -> list[float]:
    """
    Add Gaussian noise N(0, sigma) to each probability.
    Clip all values to [0, 1].
    Renormalize so they sum to 1.
    Recompute prediction as argmax of new probabilities.
    Return {"prediction": int, "probabilities": list[float]}
    """

def fake_response() -> dict:
    """
    Generate a random prediction without calling the protected model.
    prediction = randint(0, 2)
    probabilities = softmax of 3 random uniform values
    Return {"prediction": int, "probabilities": list[float]}
    """
```

### Main Defense Function

```python
def apply_defense(
    client_ip: str,
    tier: int,
    real_response: dict | None
) -> tuple[dict, str]:
    """
    Returns (response_dict, action_taken_str).

    tier 0 → return real_response unchanged, action="ALLOW"
    tier 1 → perturb_probabilities(real_response["probabilities"], sigma=0.03)
             action="PERTURB"
    tier 2 → if is_rate_limited(client_ip): 
                raise HTTPException(429, "Rate limit exceeded")
             else: perturb_probabilities(real_response["probabilities"], sigma=0.08)
             action="RATE_LIMITED" or "PERTURB"
    tier 3 → return fake_response(), action="FAKE"
    tier 4 → raise HTTPException(429, "Access denied by ModelGuard")
             action="BLOCKED"

    For tier 0–2, real_response must not be None (it was fetched from protected model).
    For tier 3–4, real_response is None (protected model was never called).
    """
```

## 11. Middleware App (`middleware/app.py`)

FastAPI app on port 8000.

**Startup:**
```python
@app.on_event("startup")
async def startup():
    init_db()  # create tables
    # fingerprint_engine loads model at import time
    # log startup with model status
```

**Request lifecycle for POST /predict:**

```
1. Extract client_ip from request.client.host
   Extract session_id from header "X-Session-ID", or generate uuid4() if missing

2. Compute inter_query_time_ms:
   last_ts = get_last_query_timestamp(db, client_ip)
   inter_query_time_ms = (now - last_ts).total_seconds() * 1000 if last_ts else 0.0

3. recent_queries = get_recent_queries(db, client_ip, window_seconds=60)

4. fingerprint_result = fingerprint_engine.classify_query(recent_queries)
   threat_score = fingerprint_result["threat_score"]

5. tier = defense.get_tier(threat_score)

6. If tier <= 2:
     forward request to protected model via httpx.AsyncClient:
     POST http://{PROTECTED_MODEL_HOST}:{PROTECTED_MODEL_PORT}/predict
     with same JSON body, timeout=5.0 seconds
     raw_response = response.json()
   Else:
     raw_response = None

7. final_response, action_taken = defense.apply_defense(client_ip, tier, raw_response)
   (apply_defense may raise HTTPException — let it propagate)

8. log_query(db, client_ip, session_id, body.features,
             raw_response["prediction"] if raw_response else None,
             raw_response["probabilities"] if raw_response else None,
             final_response["prediction"], final_response["probabilities"],
             inter_query_time_ms, threat_score, tier)

9. log_defense_event(db, client_ip, session_id, threat_score, tier,
                     action_taken, len(recent_queries))

10. Return final_response with extra headers:
    X-Threat-Score: str(round(threat_score, 4))
    X-Defense-Tier: str(tier)
    X-Session-ID: session_id
```

**Other endpoints:**

```python
GET /health
  → {"status": "ok", "fingerprint_model_loaded": bool,
     "protected_model_url": str, "db": "connected"}

GET /stats/{client_ip}
  → get_ip_stats(db, client_ip)

GET /admin/logs?limit=50
  → list of last `limit` defense_log rows as JSON
```

**Error handling:**
- If protected model is unreachable (httpx error): return HTTP 503 with `{"detail": "Protected model unavailable"}`
- If features list is not exactly 4 floats: return HTTP 422
- All exceptions log to stderr with traceback

## 17. Known Constraints and Rules

1. **Never hardcode ports, hosts, or thresholds** — always read from `.env` via `os.getenv()`.
2. **feature_extractor.py and generate_training_data.py must use identical feature computation logic** — if one changes, the other must change too. The XGBoost model's accuracy depends on this consistency.
3. **SQLite is write-serialized** — middleware and dashboard share the same file. Dashboard is read-only. Do not write from dashboard.
4. **The middleware must never crash if the protected model is down** — return 503, do not raise unhandled exception.
5. **All timestamps are UTC** — use `datetime.utcnow()` throughout.
6. **XGBoost model output is a probability, not a binary** — always use `predict_proba()[:,1]` not `predict()`.
7. **Rate limiter is in-memory** — it resets on middleware restart. This is acceptable for a demo.
8. **Docker volume `./data`** is shared between middleware and dashboard containers — do not put anything else in that volume.
